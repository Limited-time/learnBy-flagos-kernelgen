# Minimum 算子优化实践案例

> 本案例展示使用 KernelGen 生成 Minimum 算子并进行性能优化的完整过程

## 案例概述

**算子名称**：Minimum  
**算子类型**：Pointwise  
**计算密度**：0.25（1次比较+3次内存访问）  
**性能瓶颈**：内存带宽（主要）+ 计算单元利用率（次要）

## 与 Broadcast 算子的关键差异

| 特性 | Broadcast 算子 | Minimum 算子 |
|------|-------------|-------------|
| **计算密度** | ≈0（纯数据复制） | 0.25（有计算负载） |
| **数据流** | 单输入→复制→输出 | 双输入→比较→输出 |
| **UB占用** | 1×BLOCK_SIZE | 2×BLOCK_SIZE |
| **优化重点** | 内存带宽优化 | 向量化比较、双输入加载优化 |

## 关键优化点

1. **双输入加载优化**：同时加载 input 和 other
2. **向量化比较**：使用 `tl.minimum` 进行向量化比较
3. **UB 占用考虑**：调整 BLOCK_M/BLOCK_N 适应双输入
4. **Stage 数量**：双输入需要更多 stage 隐藏延迟
