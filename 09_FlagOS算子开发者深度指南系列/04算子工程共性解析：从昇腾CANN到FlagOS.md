> - FlagOS官网：https://flagos.io

## 文档概述

本文档面向有算子开发经验的工程师，分析不同算子开发框架的共性原理和差异，帮助建立跨平台的算子开发知识体系。通过对比昇腾CANN、FlagOS、PyTorch自定义算子等方案，提炼算子工程的通用方法论。

### 1.2 Shape推导机制

```
┌─────────────────────────────────────────────────────────────────┐
│                    Shape推导通用模式                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Shape推导是算子定义的核心，决定了输出的形状如何从输入推导：     │
│                                                                 │
│  1. 透传型（Element-wise）                                      │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  输入: x [B, C, H, W]                                    │   │
│  │  输出: y [B, C, H, W]  （形状不变）                       │   │
│  │  例: relu, sigmoid, add, mul                            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  2. 归约型（Reduction）                                         │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  输入: x [B, C, H, W]                                    │   │
│  │  输出: y [B, 1, H, W] 或 [B, C, H, W]（keepdim）         │   │
│  │  例: sum, mean, max, min                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  3. 变换型（Transform）                                         │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  输入: x [B, C, H, W]                                    │   │
│  │  输出: y [B, C, H*W] 或 [B, C, H/2, W/2]                 │   │
│  │  例: reshape, transpose, pooling                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  4. 矩阵运算型（Matrix）                                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  输入: a [M, K], b [K, N]                                │   │
│  │  输出: c [M, N]                                          │   │
│  │  例: matmul, linear                                     │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  5. 广播型（Broadcast）                                         │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  输入: x [B, C, H, W], bias [C]                          │   │
│  │  输出: y [B, C, H, W]  （广播后计算）                     │   │
│  │  例: add (with broadcasting)                            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────┐
│                    数据类型推导规则                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  类型提升规则（Type Promotion）：                               │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                          │   │
│  │  低精度 ──────────────────────────────────▶ 高精度      │   │
│  │                                                          │   │
│  │  int8 → int16 → int32 → int64 → float16 → float32       │   │
│  │                                           ↘ bfloat16    │   │
│  │                                                          │   │
│  │  规则：                                                  │   │
│  │  1. 不同类型运算时，提升到较高精度                       │   │
│  │  2. 整数与浮点运算时，结果为浮点                         │   │
│  │  3. 累加运算通常使用更高精度中间结果                     │   │
│  │                                                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  常见算子类型要求：                                              │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 算子类型        │ 输入类型      │ 输出类型    │ 注意事项 │   │
│  ├─────────────────┼───────────────┼─────────────┼──────────┤   │
│  │ 逐元素运算      │ 任意          │ 同输入      │ -        │   │
│  │ 归约运算        │ 任意          │ 同输入/高精度│ 累加精度 │   │
│  │ 矩阵乘法        │ float16/32    │ float16/32  │ 累加fp32│   │
│  │ Softmax         │ float16/32    │ 同输入      │ 内部fp32│   │
│  │ LayerNorm       │ float16/32    │ 同输入      │ 内部fp32│   │
│  │ 卷积            │ float16/32    │ 同输入      │ 累加fp32│   │
│  └─────────────────┴───────────────┴─────────────┴──────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

│                                                                 │

│  ┌─────────────────────────────────────────────────────────┐   │

### 2.2 FlagOS算子开发

```
┌─────────────────────────────────────────────────────────────────┐
│                    FlagOS算子开发流程                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  FlagOS算子开发方式（基于Triton）：                              │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ import triton                                            │   │
│  │ import triton.language as tl                             │   │
│  │                                                          │   │
│  │ @triton.jit                                              │   │
│  │ def add_kernel(x_ptr, y_ptr, out_ptr, n, BLOCK: constexpr):│  │
│  │     pid = tl.program_id(0)                               │   │
│  │     offsets = pid * BLOCK + tl.arange(0, BLOCK)          │   │
│  │     mask = offsets < n                                   │   │
│  │     x = tl.load(x_ptr + offsets, mask=mask)              │   │
│  │     y = tl.load(y_ptr + offsets, mask=mask)              │   │
│  │     out = x + y                                          │   │
│  │     tl.store(out_ptr + offsets, out, mask=mask)          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  FlagOS算子开发特点：                                            │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ • Python语法，学习曲线平缓                               │   │
│  │ • 跨硬件支持（NVIDIA、华为、摩尔线程等）                  │   │
│  │ • 自动优化，减少手动调优                                 │   │
│  │ • 与PyTorch无缝集成                                      │   │
│  │ • 开源生态，社区支持                                     │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 CPU算子优化技术

```
┌─────────────────────────────────────────────────────────────────┐
│                    CPU算子优化技术                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 向量化（Vectorization）                                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ # 使用SIMD指令加速                                       │   │
│  │ import numpy as np                                       │   │
│  │                                                          │   │
│  │ # 标量版本（慢）                                         │   │
│  │ def add_scalar(x, y):                                    │   │
│  │     return [a + b for a, b in zip(x, y)]                │   │
│  │                                                          │   │
│  │ # 向量化版本（快）                                       │   │
│  │ def add_vectorized(x, y):                                │   │
│  │     return np.add(x, y)  # 使用SIMD                     │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  2. 多线程并行（Multi-threading）                               │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ # 使用OpenMP或线程池                                     │   │
│  │ from concurrent.futures import ThreadPoolExecutor       │   │
│  │                                                          │   │
│  │ def parallel_compute(data, num_threads=8):              │   │
│  │     with ThreadPoolExecutor(num_threads) as executor:   │   │
│  │         results = list(executor.map(process, data))     │   │
│  │     return results                                       │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  3. 缓存优化（Cache Optimization）                              │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ # 数据局部性优化                                         │   │
│  │                                                          │   │
│  │ # 差：跳跃访问，缓存不友好                               │   │
│  │ for i in range(n):                                       │   │
│  │     for j in range(m):                                   │   │
│  │         process(data[j][i])  # 列优先访问               │   │
│  │                                                          │   │
│  │ # 好：连续访问，缓存友好                                 │   │
│  │ for i in range(n):                                       │   │
│  │     for j in range(m):                                   │   │
│  │         process(data[i][j])  # 行优先访问               │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  4. 内存对齐（Memory Alignment）                                │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ # 对齐内存访问                                           │   │
│  │ import aligned_alloc  # 或使用numpy的对齐分配           │   │
│  │                                                          │   │
│  │ # 32字节对齐（AVX256）                                   │   │
│  │ aligned_data = np.empty(shape, dtype=np.float32)        │   │
│  │ aligned_data = np.require(aligned_data,                 │   │
│  │                          requirements=['ALIGNED'])       │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
